## 三、每文件明细要求（必须包含，否则门禁不勾）

### 00-履约确认与来源快照.md（前置·强制）
- 履约模式确认结果（京东边境仓 / 米通边境仓 / 跨境直邮 / 本土仓，四选一）。
- 若边境仓：京东/米通确认 + 该仓是否平台代扣 VAT 确认（未确认标「假设值，需卖家中心确认」）。
- TK 官方资料库快照日期（`knowledge-base/index.md` 对应值）。
- 来源探测结论摘要（顺利取数 / 被阻断 + 用户配合动作，详见 `A-调研/来源日志.md`）。

### A-调研（5 文档）
| 文件 | 必含明细 |
|---|---|
| 01-产品简报 | 市场/类目、货源成本+重量体积包装、履约方式、实物/白底图清单；仿品/IP 拦截项 |
| 02-成本优化报告 | 1688 + 义乌购同款对比；**成本拆解 ¥ + 目标国两版逐项对应**；切换建议交用户 |
| 03-竞品分析 | ≥3 竞品；**每个竞品必带成交单量**；多规格逐规格列；**每个竞品各建一份时间序列**（开店/上架/总销量/首单/180天月周日均+环比）；增长下降原因；拿不到留白+备注登录动作 |
| 04-费率口径 | 佣金/交易费6%/订单处理费3000/所得税1%/VAT/关税；带来源+日期+置信度+快照日期 |
| 来源日志 | 每个来源一行：来源/URL/取数时间/登录态/结果/阻断原因/用户配合动作；被阻断给配合方案 |

### B-选品（1 文档）
- 七维加权打分（≥65 进下一流程）+ 贡献利润 >0。
- 双体系盈亏（商品卡 / 达人 A/B/0）+ 保本ROI（保本ROAS_商品卡 + 保本ROAS_达人两值）。
- 五档输出：常态 / 盈亏平衡档(#15) / 压力档(#14)。
- 达人总损失公式：`单笔贡献×寄样人数×出单率×平均出单数 − 样品成本合计`。
- **ALL-SEA 追加 B-02**：「建议国家排序」的**选择说明必须含四要素**——① 首档价在竞品中的绝对值排名；② 价格竞争力分析（门禁：**定价不高于竞品同规格最高定价**）；③ 市场规模分析；④ 品类分析（用整理的方法论：nexscope 8 维 + selection 7 维）。（T40）

- **达标通用式**：每行「目标值 + 方向(>=/<=) + 实际 + 达标公式」，禁止比率二次相除。

### 国别覆盖（T39 · 强制 · 2026-10-11 用户锁定）
> **开局绑定的目标国家集合 = 交付边界。所有执行交付物必须覆盖全部目标国家，不得只做首站国。**
- 绑定来源：`<包>/00-履约确认与来源快照.md` 的「口径绑定」节（国家 + 履约，包生命周期内不重弹）。
- 单国包（VN 单国）：天然满足，机检跳过。
- 多国包（ALL-SEA 五国 VN/TH/MY/PH/SG）：**逐件校验**——
  1. **表格 01–07 每张**必须含全部目标国家，**标准表示法 = 每国一个 sheet（2026-10-11 用户裁定）**：sheet 用国家代码命名（`VN`/`TH`/`MY`/`PH`/`SG`），并保留公共的「参数」「字段说明」sheet；各国参数与录入互不干扰，任意两国可并排对照。**只做 VN 一张表 = 不合格**。
     - 典型违规：07-单品实时盈亏看板只做 VN 单国（正确做法：`VN`/`TH`/`MY`/`PH`/`SG` 各一 sheet + 公共「参数」「字段说明」）。
  2. **文档**必须逐国覆盖：A-03 竞品分析（逐国竞品与单量，不得只有 VN）、A-05 多国费率与物流对比、C-01 全阶段SOP、C-03 复盘反馈手册、C-05 多国SOP与建议、D-01 运营数据看板、D-02 周复盘与内循环、**D-03 运营数据表模板库**。
     - **D-03 逐国实例化规则（T41）**：该文档是「运营实操表模板库」，本身为模板性质。**多国包下须对绑定国家集合逐个实例化**——每个目标国一份（或同一文档内按国家分段），填入该国的平台费率/币种/尾程物流/税务/平台规则等参数；越南仅作为参考样本，**不得写死越南**。缺某国参数时按 §三国别覆盖第 3 条留白+配合方案。
  3. 逐国数据缺失时**留白并标【未获取】+ 配合方案**（缺数诚实），**不允许「因为没查就整国不写」**。
- **适用边界（2026-10-11 用户裁定）**：T39 自本条款生效日起适用于**新开工的策略包**；生效日之前的历史包**不追溯重出**，作为已知遗留登记（机检对其报 FAIL 属预期，不作为阻塞项）。

- 三档呈现纪律：多国数字一律**逐国成行/成列 + ¥ 人民币锚定列前置**（见双币种锁）；禁止把五国压成一个「海外均值」。

## 四、分析路径（数据如何流动，必须按此顺序）

```text
用户给链接/图/产品名
   │
   ├─ STEP 1  履约模式 + 边境仓 + VAT 门禁（border-warehouse-gate.md）── 100% 第一步

   ├─ STEP 3  来源探测 + 自动化取数（source_probe.py --check → 来源日志）── 100% 第三步
   │
   ▼
A 调研   产品事实 → 成本双币种(¥+VND) → 竞品时序+单量 → 官方费率核验
   │
   ▼
B 选品   七维打分 → 单位经济双体系 → 保本ROI + 五档（常态/盈亏平衡/压力）
   │
   ▼
```
