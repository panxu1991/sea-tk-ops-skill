# 保本与保本 ROI 口径锁（2026-10-10 用户确认）

## 定义拆分（必须区分，不得混用）
> 出单率按 A（中位数）/ B（最低20%平均）/ 0（压力测试）三档计算，见下方「达人 ROI 三档」。

1. **保本（盈亏平衡）**：纯商品卡模式，不算达人、不算投流。售价 = 全部成本（采购 + 纸箱 + 边境仓 + 订单处理费 + 交易费 + 税 + 平均退货损失），利润 = 0。这是定价下限，不是「保本ROI」。
2. **保本 ROI（Break-even ROAS，分两种模式，每个定价各算一个）**：
   - **纯商品卡模式**：不含达人佣金、不含样品成本，含退货损失。`保本ROAS_商品卡 = 总成本 / 毛利`。
   - **含达人佣金模式**：计入达人佣金 + 样品成本按出单率摊销（1/P）；达人不出单损失也计入期望成本。`保本ROAS_达人 = (总成本 + 达人期望成本) / (GMV - 达人佣金 - 退货损失)`，按最终实现口径以脚本输出为准。
   - 投流费一律不计入成本；投流只看「花广告费后能否跑赢保本ROAS」。


## 达人 ROI 三档（A / B / 0）
- **A 档**：出单率 = 竞品中位数（样本量与样本列出）。
- **B 档**：出单率 = 最低 20% 竞品平均数（样本量列出）。
- **0 档（压力测试）**：出单率 = 0，达人全部不出单：单均损失 = 样品成本（1/P 全量摊销退化为 1），GMV = 0；此档只报「总损失额」，ROI 标注 N/A，不用于常规决策。
- 每档公式：`保本ROAS_达人(x) = (总成本 + 样品摊销(1/P) + 期望退货损失) / max(期望GMV(x) × (1 - 达人佣金率) - 期望退货损失, 1)`，x ∈ {A, B}；x = 0 时只输出损失总额。
## 压力测试（全运营模式，#14）

### 各运营模式五档输出（常态 + 盈亏平衡 + 压力）

每个运营模式（商品卡 / 达人A / 达人B / 达人0）都要输出三组值，不允许只给常态值：

| 档 | 定义 | 输出 |
|---|---|---|
| 常态档 | 模型默认参数（出单率取对应档、退货率取均值、汇率取当日） | 净利率 + 单量盈亏平衡点 |
| 盈亏平衡档 | 反解「净利=0」所需的关键变量值：商品卡反解最低日均单量；达人档反解最低出单率与最低平均出单数 | 平衡点变量值（如 日均X单 / 出单率≥Y% 才不亏） |
| 压力档 | 最差情形：商品卡=退货率上限+不利汇率+补货断档；达人 A/B=出单率×0.5；达人 0=全不出单 | 压力净利率 / 压力保本ROAS / 0档总损失额 |

- 盈亏平衡档用于回答「我要做到多少才不亏」，是扩量/收缩的分界线；压力档用于「扛不扛得住」；两者都不用于定价与常规决策。
- 所有值必须活公式引用主模型变量，不得静态写死。

每个运营模式都必须输出最差情形压力值，不允许只给常态值：

| 模式 | 压力情形 | 输出 |
|---|---|---|
| 商品卡 | 退货率取上限（模型变量取最大值）+ 汇率取不利时间戳 + 补货断档停售 | 压力净利率 + 压力保本ROAS |
| 达人 A 档 | 出单率中位数 × 0.5（半衰减） | 压力保本ROAS_A |
| 达人 B 档 | 出单率取 B 档再 × 0.5 | 压力保本ROAS_B |
| 达人 0 档 | 全不出单，GMV=0 | 总损失额（不报 ROI，标 N/A） |

- 压力值只用于「这个品抗不扛得住」的决策（加码/换品/退出），不用于定价与常规决策。
- 所有压力值必须活公式引用主模型变量，不得静态写死。
## 硬性输出要求

- 每个定价档位必须同时输出：净利率、单量盈亏平衡点、`保本ROAS_商品卡`、`保本ROAS_达人`、最差情形利润。
- 两套体系（商品卡 / 达人 A/B）盈亏表并列展示，不得只给一套。
- 公式必须活公式，变量引用单元格；保本ROI 不得写成静态死值。
- 与旧口径冲突处一律以本文件为准；发现旧表里「保本」一词被当成 ROI 用的，标记重算。
