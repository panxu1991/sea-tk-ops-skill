# 内容方法论深度（方法论优先，蒸馏后再输出）

> 用途：任何「分析 + 输出」前先锁方法论，再针对目标品 + 竞品/视频/商品卡综合分析。本 SKILL 不自动产出短视频，但保留方法论供分析/决策调用。

## 铁律：方法论优先

1. 先声明用哪个框架（nexscope 内容策略 / 5-beat / 9 要素 / 变量复制 / Clipcat 改写三原则等）。
2. 再蒸馏目标品 + 竞品视频/商品卡的综合信息（钩子/结构/卖点/画面/BGM/节奏/CTA）。
3. 最后输出，不「裸给结论」。

## 分析路径

```
目标品卖点 → 竞品爆款拆解(9要素) → 变量复制(保留结构/换变量) → 输出脚本/内容结构
```

- 找爆款：TikTok Creative Center / FastMoss / 竞品关联视频。
- 拆解：钩子(前3秒)、结构、卖点呈现、画面、文案、BGM、节奏、字幕贴纸、CTA。
- 变量复制：保留「结构+钩子逻辑+节奏」，替换「产品/场景/人物/钩子/BGM/文案/CTA」；一次只换 1-2 个变量做 AB。
- 一鱼多吃：1 脚本 × 5 角度 × N 达人 × M 场景。

## 约束

- 不搬运他人视频，只拆结构做变量替换。
- 不用医疗/绝对化/虚假宣称；不编造播放/转化数据。
