# 第一步门禁：目标国家 → 履约模式 → 边境仓选择 → VAT 代扣确认

> 用户要求（2026-10-10）：① **先确认做哪个国家**（决定费率/物流/VAT/退货政策整套口径）；② 边境仓价格在 TK 官网有**明确报价**（分「京东仓」和「米通仓」），**产出前必须先和我确认模式**；若选边境仓，继续询问**哪一个边境仓**、以及**边境仓模式是否产生平台代扣 VAT**。
> **这一步对后续盈亏/数值计算至关重要 → 严格嵌入，100% 执行，且放在流水线第一步。**

## 为什么必须是第一步

**国家**决定佣金档位/物流价卡/VAT/所得税/退货政策/回仓费；**履约模式**决定成本结构（有无边境仓操作费/跨境运费/报关代理/进口税金）、VAT 口径、尾程归属、退货路径。**先定国家、再定模式，后算一切**；没定就出的定价/盈亏表一律作废重做。

## 执行顺序（每跑一轮流水线，开工即执行）

```text
STEP 0  向用户确认「目标国家」（VN/TH/MY/PH/SG…）——决定费率·物流·VAT·退货政策整套口径
STEP 1  读取该国家在 TK 官网/官方文章的当前报价（无需登录即可查看，见 tk-official-distillation.md）
STEP 2  弹窗向用户确认「履约模式」——四选一，必须拿到答案
STEP 3  若=边境仓 → 追加确认「京东仓 / 米通仓」
STEP 4  若=边境仓 → 追加确认「该仓链路是否平台代扣 VAT」
STEP 5  锁定答案写入政策库 + 输入 JSON + **`<包>/00-履约确认与来源快照.md`**，后续全部用该口径
```

### ⭐ 一次性绑定（2026-10-10 用户铁律：首次选择后不再反复弹窗）

- **国家 + 履约模式（含边境仓/VAT）只在每个策略包生命周期内确认一次**。确认后答案落 `<包>/00-履约确认与来源快照.md`（「口径绑定」小节），即为该包的**唯一权威口径源**。
- 后续任何会话/任何环节（A/B/C/D、续跑、回填重算、复盘）**一律先读 00 文件，命中即视为已过门禁，不重弹**。
- 仅两种情况允许重问：①用户**主动**说换国家/换履约模式（此时全包口径重刷并重写 00）；②00 文件缺失或该小节为空（视为新包）。
- 不答默认值逻辑不变（VN + 京东边境仓 + VAT 不代扣 + 标假设），同样**写进 00 后即绑定**，不重复确认。

- 用户不答/答不上：**国家默认越南（VN）**；**模式默认「京东边境仓（一口价）+ VAT 不代扣（vat_base=0）」** 继续跑，并在交付物里**显式标注「假设值，需确认」**，不停机。
- 弹窗必须写清「默认值 / 影响哪些字段 / 不答的降级方案」，让用户一行字就能回。
- 国家与模式确定后，`references/knowledge-base/fees.json`、`logistics.json`、`policy-snapshot.md` 只取该国家记录；换国家必须**重新刷新资料库**。


## 边境仓官方口径（2026-10-10 检索，二手来源，出报告前须官方复核）

TikTok Shop 东南亚 3PL 边境仓位于广西凭祥，覆盖越南、泰国。平台**认证两家服务商：京东仓、米通仓**。

| 项目 | 京东仓 | 米通仓 |
|---|---|---|
| 位置 | 凭祥综合保税区（保税仓） | 凭祥保税区外普通仓 |
| 业务 | 支持保税 + 非保（品牌/出口退税优先选） | 仅非保 |
| 仓内操作费 | **一口价 1.24 RMB/单**（不分重量段） | **阶梯**：≤50g 0.4；≤250g 0.9；≤500g 1.4；>500g 1.5 RMB/单 |
| 免仓租 | 90 天 | 60 天 |
| 跨境运费 | 按**实重**计费（省 40%+，重量越大越省） | 同左 |
| 报关代理费 | 收（进/出口关务代理） | 收 |
| 进口税金 | 服务商**代缴后向商家收取**（含海关手续费，如越南海关 10K VND） | 同左 |
| 尾程 | 平台尾程服务商配送，**费用由消费者承担**（商家无成本） | 同左 |
| 时效（越南） | 河内 2-4 天 / 胡志明 4-7 天 | 同左 |

**关键结论（影响 VAT 口径）**：边境仓链路里，**进口税金由「边境仓服务商」代缴后向商家收取**，与「平台代扣」是两条不同的链路。因此：
- 若走**边境仓**：默认 VAT 口径 = **不代扣**（`vat_base=0`），进口税金走「服务商报关代缴」成本项 → **但仍须 STEP 4 与用户确认**是否有平台侧代扣（平台规则可能变化）。
- 若走**跨境直邮**：VAT 口径**以官方为准**（见 `tk-official-distillation.md` + `policy-snapshot.md`），平台按官方规则代扣 10%。

## 两套计价方式（**互斥**，2026-10-10 用户锁定；统一由 `unit_economics.py` 的 `fulfillment` 切换）

```text
【跨境直邮 fulfillment=direct】
单笔全成本 = 采购价 + 国内头程 + 货代贴单费 + 跨境物流费 + 包装耗材 + 退货准备金
             + VAT 平台代扣 10%（基数=商品实付；vat_base 自动=商品实付）
  跨境物流费 = 官方价卡（VN Economy：500₫(≤10g) + 500₫/10g；60g=3,000₫）

【边境仓 fulfillment=border】
单笔全成本 = 采购价 + 国内头程 + 仓内打包费用 + 边境仓操作/贴单费
             + 跨境运输费（官方专线 RMB/kg→VND/单） + 清关费用 + 仓储费(90天后摊销)
             + 包装耗材 + 退货准备金
             + VAT【=0】（进口税金由服务商代缴，行「清关费用」实报实销）
  仓储费：90 天免租期内 = 0；超过免租期按仓储价按单摊销
  ⚠️ 清关费用**按模式看**（2026-10-10 用户口径）：**仅保税链路收**（如越南代理申报 10,000₫/票、保税 1210 报关 400 元/票）；
     **不保税（非保）不收此费** → 脚本 `bonded=False` 时 `customs_clearance_fee` 自动不计。
     可由用户报价 → **一次报价后沿用，直到用户更新价格再更新**（写入参数区黄格）

【两种模式共同】
  尾程运费   = 买家承担（卖家成本 0；仍计入 6% 交易手续费基数）
  样品尾程   = **卖家承担**（记入样品成本 sample_extra_cost）
  平台费/税  = 按平台最新规则（佣金按官方类目表、交易费、订单处理费、所得税、VAT）
  退货准备金 = 二选一：
               (a) 分项法：退货率 × (该模式物流与采购成本合计 + 包装 + 交易手续费 + 订单处理费 + 退货回仓费)
               (b) 模板法（用户自有核算模板口径）：退货率 × 退货损耗率 × 售价
  退货回仓费 = **目的国各 Zone 尾程费用均值（T25 结案，标 assumed）**：官方《边境仓价卡（对外）》当地派送价卡 0.5kg 各 Zone 尾程行求均值（VN=31,929₫，取自 17 Zone 行）；**既不是「无单价待报价」也不是 0**。无逆向物流实测账单前一律按此估算，首笔实测后回填（见 `knowledge-base/logistics.json` 的 `return_warehouse_fee` 字段，脚本默认 `return_warehouse_fee=31929`）。
  样品成本/份 = 该模式成本构成项 + 包装 + 尾程运费(卖家承担)
```

> **口径切换按「初始选择」匹配，不清零**（2026-10-10 用户要求）：脚本 `apply_mode_rules()` 只决定本次计入哪些项 + VAT 基数，**不修改任何输入值**；另一模式的字段保留原值但不参与计算（`mode_cost_items()` + `_effective()`）。这样随时切回原模式不会丢数据。

## 弹窗话术模板

```text
【目标国家确认｜第 0 步，决定费率/物流/VAT/退货政策整套口径】
请选一个（回一个词即可）：越南(VN) / 泰国(TH) / 马来(MY) / 菲律宾(PH) / 新加坡(SG) / **东南亚所有国家(ALL-SEA)**
默认：越南(VN)。
影响：佣金档位、物流价卡、VAT/所得税、退货与回仓费、清关费。
若选 ALL-SEA → 我对所有国家做整体策略交付，并按数据给出**建议国家排序**（见 country-matrix.md）。

【履约模式确认｜第一步，影响后续所有盈亏计算】
请选一个（回一个词即可）：
A. 京东边境仓（一口价 1.24 元/单，支持保税，90 天免租）  ← 默认
B. 米通边境仓（阶梯 0.4-1.5 元/单，仅非保，60 天免租，轻小件更省）
C. 跨境直邮（不经边境仓）
D. 本土/平台海外仓
默认：A。影响：成本结构 + VAT 口径（A/B 默认不代扣；C 以官方为准）+ 退货路径。
若选 A 或 B，我还会追问：①哪个仓？②该仓链路是否平台代扣 VAT？
不答 → 按「VN + A + VAT 不代扣」继续，交付里标「假设值，需卖家中心确认」。
```
